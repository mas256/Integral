\section{増減と凹凸}\label{節:増減凹凸}
前節で,\,$f'$ の符号から増減が分かった.では,\,$f'(c)=0$ となる点では何が起こっているのだろうか.内点で極値をとれば $f'(c)=0$ であったが,逆は成り立たない.\,$f(x)=x^3$ は $f'(0)=0$ だが,\,$0$ の前後でも増加し続ける.\,$f'(c)=0$ は極値の候補を探す条件であり,極値を保証する条件ではない.

極値かどうかは,その点の前後で $f'$ の符号がどう変わるかで判定する.\,$f'$ の符号が $+$ から $-$ に変われば,増加から減少に転じるので極大であり,\,$-$ から $+$ に変われば極小である.

ここで1つ断りをいれておこう.本節で扱う関数は,考える区間で2回微分でき,その第2次導関数は連続であるとする.\footnote{微分できない点を含む関数では,その点も極値や最大・最小の候補に加えて調べる.}

次に,グラフの曲がり方を調べよう.導関数をもう一度微分した $f''=(f')'$ を\textbf{第2次導関数}という.\,$f''>0$ なら,前節の結果を $f'$ に使うと,接線の傾き $f'$ が増加する.このときグラフは\textbf{下に凸}であるという.\,$f''<0$ なら傾きが減少し,グラフは\textbf{上に凸}であるという.たとえば $y=x^2$ は下に凸で,\,$y=-x^2$ は上に凸である.

この呼び方は,接線との位置関係から確かめられる.\,$f''>0$ の区間で点 $a$ を固定し,\,$x>a$ とすると,平均値の定理により
\[
 f(x)-f(a)=f'(c)(x-a)\qquad(a<c<x)
\]
となる.\,$f'$ は増加するから $f'(c)>f'(a)$ であり,\,$x-a>0$ より
\[
 f(x)-f(a)>f'(a)(x-a)
\]
を得る.\,$x<a$ の場合も,\,$x<c<a$ で $f'(c)<f'(a)$ となることと $x-a<0$ を合わせれば,同じ不等式を得る.\,$f(a)$ を右辺へ移すと
\[
 f(x)>f(a)+f'(a)(x-a)
\]
であり,右辺は点 $a$ における接線の式である.つまり,下に凸なグラフは接線の上側にあるのだ.\,$f''<0$ では不等号が逆になり,グラフは接線の下側にある.

凹凸が切り替わる点を\textbf{変曲点}という.\,$f''$ は連続なので,変曲点は $f''=0$ となる点から探せる.ただし,\,$f''=0$ だけでは十分でない.\,$y=x^4$ は $x=0$ で $f''=0$ となるが,その前後でともに下に凸である.ここでも,前後で $f''$ の符号が変わるかを確かめる.

以上から,\,$f'$ と $f''$ をそれぞれ因数分解し,符号が変わる点を境に表を作れば,増減と凹凸を一度に読み取れる.このような表を\textbf{増減表}という.閉区間で最大・最小を求めるときは,極値だけでなく区間の両端も候補になる.

\begin{bookpoint}
\textbf{POINT}\par
$f'$ を因数分解して符号の変わる点を求め,増減表を作る.閉区間の最大・最小は,極値と両端の値を比べて決める.
\end{bookpoint}

\begin{example}{極値と最大・最小}
$f(x)=x^3-3x$ の増減と凹凸を調べ,区間 $[-2,3]$ における最大値・最小値を求めよ.
\end{example}
\paragraphbf{方針}
$f'$ と $f''$ を因数分解して増減表を作り,極値と両端の値を比べる.

\paragraphbf{解答}
$x<-1$ と $x>1$ で増加,\,$-1<x<1$ で減少する.極大値は $2$ ($x=-1$),極小値は $-2$ ($x=1$) である.\,$x<0$ で上に凸,\,$x>0$ で下に凸であり,変曲点は $(0,0)$ である.区間 $[-2,3]$ での最大値は $18$ ($x=3$),最小値は $-2$ ($x=-2,1$) である.

\paragraphbf{解法}
導関数を因数分解すると,
\begin{align*}
 f'(x)&=3x^2-3\\
 &=3(x+1)(x-1)
\end{align*}
となる.また,
\[
 f''(x)=6x
\]
である.\,$f'$ は $x=\pm1$ で,\,$f''$ は $x=0$ で符号が変わる.区間 $[-2,3]$ での増減表は次のようになる.
\[
\begin{array}{c|ccccccccc}
 x&-2&&-1&&0&&1&&3\\ \hline
 f'(x)&&+&0&-&-&-&0&+&\\
 f''(x)&&-&-&-&0&+&+&+&\\
 f(x)&-2&\nearrow&2&\searrow&0&\searrow&-2&\nearrow&18
\end{array}
\]
したがって極大値は $f(-1)=2$,極小値は $f(1)=-2$ である.また,\,$x<0$ で $f''<0$,\,$x>0$ で $f''>0$ だから,\,$x<0$ で上に凸,\,$x>0$ で下に凸であり,原点 $(0,0)$ は変曲点である.

最大・最小の候補は,極値をとる $x=-1,1$ と両端 $x=-2,3$ である.
\[
 f(-2)=-2,\quad f(-1)=2,\quad f(1)=-2,\quad f(3)=18
\]
を比べて,最大値は $18$ ($x=3$),最小値は $-2$ ($x=-2,1$) である.
