\section{ヒント}\label{節:総合ヒント}

以下では,各問題を何に帰着させるかと,そのための最初の変形を示す.

\begin{enumerate}[label=\textbf{\thechapter.\arabic*},leftmargin=*]
 \item 分子を$1+x^2$で割り,整式と$\frac{x}{1+x^2}$の和にする.後者は分子が分母の微分の定数倍なので,対数の積分に帰着する.
 \item $u=1+x^2$と置いて$u^{\frac12}$の積分に帰着させる.\,$x\dd x$をそのまま$\dd u$で表し,区間も$u$の値に直す.
 \item $\log x$を微分する側に選んで部分積分し,整式の積分に帰着させる.
 \item $G(u)=\int_0^u\sqrt{1+t^2}\dd t$と置いて$F(x)=G(x^2)-G(x)$と書き,基本定理と合成関数の微分に帰着させる.
 \item $x=-t$と置いて書き直した積分を元の積分と足し,指数関数を含む重みを消して整式の積分に帰着させる.\,$1+x^2$は偶関数である.
 \item 交点と上下関係を調べる.面積は高さの差を,体積は回転軸からの2つの距離の平方の差を積分する.
 \item 端点を微分して$H'(a)$を求め,極値の候補を出す.値の比較は$y=a-\frac12$と置いて積分区間の中心から測り,\,$H$を$y$の式として平方完成する.
 \item $u=1+x^2$と置けば,\,$x^3\dd x=\frac12(u-1)\dd u$となる.その後,\,$\log u$を微分する部分積分に帰着させる.
 \item 1項を$\frac1n$と$\frac{k}{n}$だけで表し,区分求積法で定積分に直す.積分は分子を分母と定数の差にして求める.
 \item 区間$[x-1,x]$は常に$0$を含むので,断面は円板である.半径は両端の軸からの距離の大きい方であり,それが切り替わる点で積分を分ける.
 \item $K_n+K_{n-1}$では分母が消え,漸化式が得られる.極限には$0\leqq K_n\leqq\int_0^1x^n\dd x$を使い,交代和は漸化式に$(-1)^{k-1}$を掛けて足し合わせる.
 \item 積分を$x=1$で分け,\,$0$付近は$x^\alpha$,無限大付近は$x^{\alpha-2}$との極限比較に帰着させる.2つの条件を同時に満たす範囲を求める.
 \item 積分を$x\int_0^xf(t)\dd t-\int_0^xtf(t)\dd t$に分けて微分し,\,$f''=f$と初期値を導く.その後,\,$\e^{-x}(f+f')$の微分を考えて$f+f'$を求め,同様に$\e^xf$の微分から$f$を求める.
 \item まず2つの制約を満たす一次関数$\ell(x)$を求める.\,$g=f-\ell$と置いて$\int_0^1\ell g\dd x$を調べ,\,$\int_0^1f(x)^2\dd x$を2つの平方の積分の和に分ける.
 \item $x'(t)=2\sin^2t>0$より,面積と体積は$t$の積分に直せる.どちらもウォリスの積分公式に帰着する.弧長では$\sqrt{x'(t)^2+y'(t)^2}$を整理してから積分する.
 \item (1) $\sin u$の有限テイラー公式に$u=x^2$を代入し,多項式の積分と剰余の評価に帰着させる.六次テイラー多項式では偶数次の係数が$0$になるので,剰余は七階微分で評価できる.(2) $u=x^2$と置く.収束には部分積分,絶対値の積分の発散には長さ$\pi$の区間ごとの下からの評価を使う.
 \item 部分積分で$(1-x^2)$の指数を1つ下げて漸化式を作る.極限は,\,$x=\cos t$と置いて$C_n$を$\sin$の奇数べきのウォリスの積分に帰着させ,隣り合うウォリスの積分の比と積を組み合わせる.
 \item $x$を$-x$にした積分と元の積分を足すと,\,$\frac1{1+\e^x}+\frac1{1+\e^{-x}}=1$により指数関数を含む重みが消える.その後,半角公式で根号を外し,\,$x=2t$,さらに$u=\sin t$と置く.残る積分の$(1-u^2)$の指数は整数なので,部分積分で1つずつ下げられる.

 \item $b_{n+1}$の分子と分母をそれぞれ平方に直し,\,$b_{n+1}=b_n^2$を確かめる.その一般項から$x_n$を解く.
 \item 弦と放物線の差は$(x-a)(b-x)$となる.三角形は,弦の中点を通る縦の線分で2つに分ける.
 \item (1) 二項定理で展開し,端点で残る導関数を調べる.(2) $\e^x$を積分し続ける部分積分を繰り返す.(3) $x(1-x)\leqq\frac14$で評価する.\,$\e=\frac ab$と仮定すると,\,$bI_n$が$0$と$1$の間の整数になって矛盾する.
 \item $\frac1{m+k}$を$x^{m+k-1}$の積分で表し,二項定理で和を1つの積分にまとめる.
 \item $x^2-(ax+b)=p(x)+(1-a)x-\frac16-b$と書いて平方を展開し,(1)を使って交差する項を消す.
 \item (1) $r=1$を境に,四分円が正方形からはみ出す.(2) 下側の三角形で$x$を固定し,内側の積分で$y=xt$と置く.
\end{enumerate}
