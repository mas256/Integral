# 文書作成規格 第3版 文体と書き方の型(工程1で使う)

## Y1 使い方

- Y1.1 型は、author-style を新しく作るときに、テンプレートの問いへの答えの候補として示すものである(R3.3)。型のまま使うか、事項ごとに変えるかは、依頼者が決める。author-style の欄が記入済みの事項には、型を示さない。
- Y1.2 工程3・4は、この型ではなく、author-style.md に従う。

## Y2 文書ごとに決める事項

「定めなし」は、出典に定めがなく、工程1で決める事項である。

| 事項 | 講義型 | 実務型 |
| --- | --- | --- |
| 向く文書 | 教科書、解説。通読して理解を積み上げる文書 | 起案書、企画書、報告、引き継ぎ書、連絡文 |
| 文体 | だ・である調 | です・ます調 |
| 語り口 | 熟練の教師の講義。呼びかけをよく使う | 定めなし |
| 始め方 | 身近な話題・直感的推測・素朴な疑問から始めることがある(任意) | これから何について述べるかを最初に示す。説明・提案では結論を先に置く |
| 進め方 | 演繹的に、ステップバイステップで進める | 結論→根拠→具体例→結論を基本に、読者が自然に追える順に並べる |
| 反復 | 言い換えを多用する | 簡潔に書く。不要な文と重複を削る |
| 一文 | 難解な演繹は細かく分割する。流麗さを保つ | 1文に1内容。修飾を重ねすぎない |
| 接続 | ディスコースマーカーを多用する | 接続詞を文頭に置き、続く内容を読者に予告する |
| 根拠の示し方 | 矛盾と飛躍のない演繹 | 数字と事実。課題・デメリットと改善策も書く |
| 脇道 | より大きな概念で重要な場合にだけ書く | 定めなし |
| 締め方 | 面白さ・便利さ・他の事柄とのつながりを、書けるときに書く(任意) | 主張をもう一度示す。提案では今後の流れを書く |

## Y3 講義型

### 1.確かめられる規則

- 文体はだ・である調とする。です・ます調や砕けた口語を混ぜない。
- 係り受けと修飾を明確にする(どの語に係るかが一通りに定まらない文は違反)。
- 脇道は、扱っている事柄が属するより大きな概念で重要な場合にだけ書き、そのつながりと理由を本文に示す。

### 2.判断の入る方針

- 明瞭な論理の流れと、認知負荷の削減を最も重視する。
- 章や節の議論を、身近な話題・直感的推測・素朴な疑問から始めることがある。ただし、無理に作らない。
- 結論部分で、それがどれだけ面白いか・便利か・他の事柄とどう繋がるかを書けるときに書く。
- 論理はなるべく演繹的に、矛盾と飛躍なく、ステップバイステップで進める。
- 未知の事柄を極限まで減らす。
- 難解な演繹は細かく分割して、明瞭な論理にする。
- 言い換えとディスコースマーカー(また、たとえば、しかし、すなわち、なぜなら等)を多用する。
- 熟練の教師の講義を目指し、呼びかけをよく使う。
- 文は流麗で、日本語として質が高い。

## Y4 実務型

### 1.確かめられる規則

- 文体はです・ます調とする。だ・である調や砕けた口語を混ぜない。
- 係り受けと修飾を明確にする(どの語に係るかが一通りに定まらない文は違反)。

### 2.判断の入る方針

- 相手の視点に立ち、読者の認知負荷を限界まで下げる。
- 簡潔に書く。不要な文と重複を削る。
- 1文に1内容とする。主語と述語を明確にし、修飾を重ねすぎない。情報のまとまりごとに読点を打つ。
- 章や段落の冒頭で、これから何について述べるかを示す。
- 説明・提案では結論を先に示し、根拠、具体例の順に続ける。ただし、形式に縛られず、内容が明確に伝わることを優先する。
- 読者の前提知識に合わせ、大前提から順に始める。専門用語を必要以上に使わず、必要なら説明する。
- 主張には理由と具体例を添え、根拠は数字や事実で示す。提案では、課題・デメリットと改善策、今後の流れも書く。
- 読みながら不要な「なぜ?」が生まれないようにする。ただし、意図して残す「引き」は除く。
