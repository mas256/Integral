# 文書作成規格 第3版 工程0:壁打ち(任意)

この工程の目的は、何を書くかがまだ固まっていない依頼者と話しながら、書く内容を広げ、要件定義(工程1)の材料を集めることである。内容を膨らませる段階なので、定めは少なくしてある。ここに書かれていないことは、依頼者の求めに合わせて自由に進めてよい。本文も要件定義書も、この工程では書かない。

## Z1 進め方

- Z1.1 依頼者の言葉を引き出すところから始める。どんな読者のどんな場面を思い浮かべているか、書こうと思ったきっかけは何か、何が気になっているか、を尋ねる。
- Z1.2 話の向きと深さは、依頼者に合わせる。質問を重要な事項だけに絞る定め(W5.1)、質問を1回にまとめる定め(W5.2)、承認を待つ定め(W2.1)は、この工程では適用しない。
- Z1.3 依頼者の案への批評(W5.3)は、求められたときと、案の弱点が後の工程に響くと考えたときに行う。同調を目的にしない点(W4.6)は、この工程でも変わらない。

## Z2 AIの案

- Z2.1 論点、切り口、反論、たとえ、構成の案を、広く出してよい。依頼者が挙げていない論点を出すことも妨げない。
- Z2.2 AIが出した案は、壁打ちメモに「AI」と記して、依頼者の案と区別する。発言のたびに「AI提案」と断る必要はない。
- Z2.3 AIの案が文書の要件に入るのは、工程1で依頼者が採用を明示したものだけである(W1.1は工程1から適用する)。この工程で依頼者が「採る」と言った案も、工程1でもう一度確かめる。

## Z3 下調べ

- Z3.1 下調べは、広く浅く行う。どんな論点があるか、既にどんな議論や資料があるかを見渡すことが目的である。どこまで深く調べるかは、依頼者の指示に従う。指示がなければ、深追いしない。
- Z3.2 調べた事柄には、出典を添える。出典のない事柄は、AIの記憶によるものと明記する。
- Z3.3 この工程で挙がった事実・数値・引用は、すべて未確認として扱う。本文に使う前に、W4.4に従って調べ直す。

## Z4 壁打ちメモと終わり方

- Z4.1 成果物は、壁打ちメモ1つである。話が進むたびに書き足す。書式は次のとおりとし、項目は増やしてよい。

```text
# 壁打ちメモ:[仮の題](日付)
1. 出た論点:論点|誰の案か(依頼者/AI)|依頼者の反応(採る/捨てる/保留/未確認)
2. 読者と目的について分かったこと(依頼者の言葉で)
3. 調べた事柄:事柄|出典|未確認
4. まだ答えの出ていない問い
```

- Z4.2 工程1へ移るのは、依頼者が移ると言ったときである。AIは、「想定読者」と「読後に期待すること」(R2.2の必須の2項目)を埋める材料がそろったと見たときに、移ることを提案してよい。
- Z4.3 承認は求めない。壁打ちメモは、工程1の資料になる(R1.1)。執筆と改稿の担当には渡さない(W2.9)。
