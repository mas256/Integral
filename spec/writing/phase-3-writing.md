# 文書作成規格 第3版 工程3:執筆

この工程の目的は、承認された草案を、想定読者が飛躍も不要な負担もなく読める本文にすることである。何を書くかは草案が決めている。この工程で決めるのは、どう書くかだけである。

## M1 根拠と範囲

- M1.1 本文の根拠にするのは、承認済みの要件定義書、author-style.md、承認済みの草案、依頼者が渡した素材だけである。工程1・2の議論に出たが成果物に書かれていない内容を、本文の根拠にしない。
- M1.2 草案の項目を、すべて、草案の順に書く。草案にない論点・題材・例・脇道を足さない。草案の項目を省かない。
- M1.3 執筆者が決めてよいのは、言い回し、文の区切り、接続、言い換えと短い再提示の置き方、歩幅を合わせる文の置き方と形、段落の切り方、仮題の範囲での見出しの文言、〔任せる〕と記された事項である。
- M1.4 書いている途中で草案の不足に気づいた場合は、次のとおり扱う。
  - 一通りに定まる中間過程(式変形の途中、直前の項目から論理的に一つに決まる一歩)は補い、引き渡しメモに記録する。
  - 選択の余地がある不足(どの例・根拠を使うか、新しい概念を導入するか、順序を変えるか)は補わない。争点に当たる場合は、執筆を止めて質問する。争点でない場合は、その箇所に【要確認:内容】と記して先へ進み、引き渡しメモにまとめる。
- M1.5 草案のとおりに書くと飛躍・負担が生じると判断した場合も、黙って構成を変えず、M1.4と同じに扱う。草案の内容に誤りを見つけた場合(W4.4)は、訂正して書き、訂正した点を引き渡しメモに記録する。訂正の内容が一通りに定まらない場合は、【要確認】とする。

## M2 書く手順

書く範囲(章または節)ごとに、次の順で進める。M2.1とM2.2で定めたことは、出力しない。

- M2.1 範囲の下調べ(範囲ごとに1回):
  1. 草案のその範囲の項目を順に読み、項目ごとに、その項目で初めて使う語・記号・事実を拾う。
  2. 拾ったものの一つひとつが、次のどれに当たるかを確かめる。想定読者の前提知識にある/それより前の項目で示される/その項目の中で導入する。どれにも当たらないものは、草案の不足としてM1.4で扱う。
  3. author-style の用語・表記表から、この範囲に出る固定語の採用形と、関わる表記の決めを確かめる。
  4. 草案の注記(詳しさ、強調、式、図、表、例、始め方、締め方、脇道、前提、任せる)を拾う。
- M2.2 項目ごとの組み立て(書く前に):
  1. 変化:この項目を読み終えた読者に起こることを、「読者が〜と分かる」「読者が〜できる」の一文で定める。
  2. 出発点:読者がこの位置までに持っている情報のうち、この項目が使うものを挙げる。
  3. 入口:何から書き始めるかを決める。直前の項目の結論、問い、観察、例のどれかにする。草案に〔始め方〕があれば、それに従う。
  4. 道筋:出発点から変化までに必要な文を、読者が追う順に並べる。一つの文が担う役目(事実、理由、操作、結果、例、言い換え)は、一つを基本とする。次の3つをすべて満たす場合は、一文に二つ持たせてよい。
     - 二つが直結している(理由と結果、操作と結果、事実とその言い換え)。分けると、接続の語を足すだけの文になる。
     - どちらも、想定読者が既に知っているか、一目で追える。
     - 係り先が一通りに定まる(M3.5)。
     - 新しい概念の導入と、その概念を使った主張は、一文に入れない。
  5. 出口:次の項目へ何を渡して終えるかを決める。次の項目が使う結論や問いで終える。
- M2.3 書く:M2.2の道筋の順に書く。草案の箇条書きを一文ずつ文章に直して並べるだけにしない。草案の1行が、本文では複数の文になってよい。
- M2.4 範囲を書き終えたら、M4の点検を行ってから返す。
- M2.5 長い文書は、章または節ごとに書いて示す。依頼者が区切り方を指定した場合は、それに従う。

## M3 書き方

著者規則(author-style)が次の規則と食い違う場合は、著者規則に従う。ただし、正確性(W4.4)は著者規則で変えない。M3.1〜M3.7は、負担の原因(N2)の一つひとつについて、それを作らない書き方を定める。

- M3.1 未知の語や背景を、突然出さない(原因:未知)。
  - 語・記号は、それを使う文より前で導入する。導入する文では、それが何であるかを述べる。
  - 記号と略語は、初めて出すときに、何を表すかを言葉で書く。
  - 既に示した事柄を離れた位置で使うときは、距離に応じて、次のとおり再提示する。

    | 示した位置からの距離 | 書き方 |
    | --- | --- |
    | 同じ節で、間に別の話題を挟まない | 添えない |
    | 同じ章の別の節、または間に別の話題を挟む | それが何であったかを一句で添える |
    | 別の章、または読者が覚えていると期待できない | 内容を1〜2文で再提示し、示した位置を添える |

  - 必要性で一段ずらす。その事柄がなくても今の文が理解できる場合は、一段軽くする。今の箇所の理解に欠かせない場合は、一段重くする。草案に〔前提〕の注記がある項目は、欠かせないものとして扱う。
  - 想定読者の前提知識にある語は、説明しない。
- M3.2 なぜ今その話をするのかを、読者に分からせる(原因:関連)。
  - 節・項の最初の数文で、そこで何を扱うかが分かるようにする。形は問わない(宣言、問い、身近な話題のどれでもよい)。
  - 話題を変える文では、直前の話題との関係(続き、別の場合、理由、例、まとめ、脇道)が分かるようにする。
  - 接続の語を書いたら、前後の関係を、因果、対比、例示、言い換え、追加、条件のどれか一語で言えるかを確かめる。言えない場合は、関係を述べる文を足すか、接続の語を外す。
  - 因果や論理の欠落を、接続の語で隠さない。
- M3.3 結論や操作の理由を、飛ばさない(原因:理由)。
  - 結論や操作を書いたら、その理由が、同じ文、直前の文、直後の文のどこかにあるかを確かめる。
  - 式を変形する行では、どの操作をしたかを読者が追えるようにする。想定読者が一目で追えない変形を、一行にまとめない。
  - 「明らかに」「容易に分かる」と書いて過程を省かない。ただし、想定読者の前提知識で実際に明らかな場合は、省いてよい。
  - 手順や解法では、何をするかと、なぜそうするか(着眼)を、分けて書く。
- M3.4 新しい事柄を、一度に複数抱えさせない(原因:同時)。
  - 一つの数文単位で新しく導入するのは、一つの理解上のまとまり(N1.16)にする。一方だけでは読者が何も判断できない概念の組は、同じ単位で導入してよい。独立に理解できる概念は、単位を分け、一つ目の理解が成立してから二つ目へ進む。
  - 新しいまとまりを導入する数文単位が2つ以上続く場合は、その間に、歩幅を合わせる文(N1.17)を置く。形は、ここまでの要点の確認、読者への呼びかけ、導入した概念を使う短い例のいずれかにし、author-style に合うものを選ぶ(呼びかけを使わない文体では、要点の確認か例にする)。1か所につき1〜2文とし、積み上げない。直後の項目が、導入した概念を使う例である場合は、それで足りる。
  - 場合分けをするときは、先に場合の全体を示し、その後で一つずつ扱う。
  - 問いや条件を後へ持ち越すときは、持ち越すことと、どこで扱うかを読者に示す。
- M3.5 主述・修飾・指示対象を、一通りに定める(原因:係り)。
  - 修飾する語句は、係る語の近くに置く。係り先が二通りに読める場合は、語順を変える、読点を打つ、文を分ける、の順に試す。
  - 指示語(これ、それ、この〜、前者など)を書いたら、指す先が、直前の文までで一つに決まるかを確かめる。決まらない場合は、名詞で言い直す。
  - 文の途中で主語が変わる場合は、変わった主語を書く。
  - 「AとBのC」「〜ない〜だけ」のように、並列や否定の範囲が二通りに読める形を避ける。
- M3.6 例・図・式・表を、一般論と結び付ける(原因:対応)。
  - 例の前に、何の例であるかを示す。例の後に、例のどの部分が一般論のどの部分に当たるか、例から何が分かるかを書く。
  - 式の直前に、何を表す式か、または何を求める式かを書く。式の中の記号は、すべて既に導入されているようにする。式から読み取ってほしいことがあれば、直後に書く。
  - 図と表は、本文から参照し、どこを見ればよいかを書く。それを導く文の近くに置く。
- M3.7 離れた情報の照合を、読者にさせない(原因:照合)。
  - 比べる二つの事柄は、近くに置くか、表にする。
  - 式・図表・節を参照するときは、番号に加えて、それが何であるかを一句で添える(例:「式(3)の漸化式」)。
  - 何度も使う結果は、使う位置で短く再提示する。
- M3.8 用語と表記:author-style の用語・表記表に従う。
  - 固定語(N1.10)は採用形で通し、別の語で呼ばない。
  - 言い換えは、説明を別の角度から述べ直すことであり、N1.13の3条件を満たす形で行う。目印(すなわち、つまり等)か並置で同じ内容だと示し、固定語の名前は変えず、述べ直した後は固定語に戻る。
  - 表に決めのない表記は、文書の中で一つの形に通し、選んだ形を引き渡しメモに書く。
- M3.9 脇道(草案に〔脇道〕とある項目):
  - つながる先と、そこで重要である理由を本文に示す。
  - 脇道に入ること・戻ることが、目印で読者に分かるようにする。
  - 演繹の途中に割り込ませない。
- M3.10 書かないもの:
  - 草案にない前置き・まとめ・案内の文。ただし、歩幅を合わせる文(M3.4)と、離れた事柄の再提示(M3.1)は、これに当たらない。
  - 同じ内容の反復(著者規則が定める言い換えを除く)。
  - 断り書きの積み上げ。
  - 「必ず結論から」「必ず具体例から」といった形式を、自分で課さない。
- M3.11 文体:
  - 著者規則と文体の見本に従う。見本がある場合は、語尾・語彙に加え、着眼点、問いかけ、説明の詳しさ、文の間合いも合わせる。
  - 自分の好みの文体に寄せない。
  - 任意の方針(N3.3)は、草案に指定のある箇所と、内容が無理なくそれを許す箇所でだけ使い、すべての単位に機械的に当てはめない。
  - 頻度の方針(N3.4)は促しとして扱い、内容に合わない箇所に無理に入れない。
- M3.12 体裁:
  - 見出し・箇条書き・表・強調は、要件定義書の媒体と形式に従う。
  - 指定がなければ地の文を基本とし、並列の項目・手順・比較にだけ箇条書きや表を使う。
  - 段落は、一つの話題で区切る。
- M3.13 事実・推測・意見を、読者が区別できるように書く。

## M4 点検(返す前に行う)

点検は、規則への適合を、照合と検索で確かめる作業である。本文の出来の評価ではない。見つけた不適合は直す。直せないものは、引き渡しメモに書く。

- M4.1 草案との対応:草案の項目を上から順にたどり、項目ごとに、対応する本文の位置を確かめる。すべての項目が、草案の順にあるか。草案にない論点・題材・例・脇道が本文にないか。
- M4.2 語の導入:M2.1で拾った語・記号が、使う位置より前で導入されているか。
- M4.3 用語と表記:固定語が採用形で書かれているか。表記が、用語・表記表と、選んだ形に揃っているか(検索で確かめる)。
- M4.4 確かめられる規則:author-style の確かめられる規則の一つひとつについて、反する文がないか。検索で確かめられる規則(文末の調など)は、検索で確かめる。
- M4.5 参照:式・図表・節の番号と、「前述の」「後で述べる」の指す先が、実際にあり、内容が一致するか。
- M4.6 正確性:式・導出・数値・引用を、W4.4に従って確かめたか(再計算と再導出は、自分で行う)。外部の資料に当たらないと確かめられないものが、位置と確かめたい事柄とともに、引き渡しメモに載っているか(W2.11)。
- M4.7 【要確認】:本文中の【要確認】が、すべて引き渡しメモに載っているか。

## M5 返すもの

- M5.1 本文:要件定義書に定めた形式で返す。本文の中に、執筆上の注釈を混ぜない。ただし、【要確認】は記す。
- M5.2 引き渡しメモ:次の6項目を短く書く。該当のない項目は「なし」と書く。
  1. 補った中間過程(位置と内容)
  2. 草案から変えた点・訂正した点と、その理由
  3. 【要確認】の一覧
  4. 未確認の事実・数値・引用(位置と、確かめたい事柄。窓口が検証の要求にまとめる)、点検(M4)で直せなかった不適合
  5. 判断上の仮定
  6. author-style への追記案(新たに固定すべき用語、選んだ表記)
- M5.3 本文の出来についての自己評価を書かない。評価は、執筆とは別の工程(文書レビュー)が担う。
- M5.4 依頼者から修正を求められた場合:内容・順序・詳しさの変更は、草案を先に改めてから本文に反映する(W2.3)。表現の変更は、本文だけを直す。求められた箇所以外を書き換えない。
