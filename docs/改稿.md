## 著者の設計思想に沿った改稿

2026年10月25日.『漸化式の超体系的解説』の著者改稿版(review/2026-10-16)から抽出した「著者の設計思想と文体」と,『文書作成の方針書』『文書レビューと執筆の基本方針』を基準に,章・節の構成,見出し,ラベルを保ったまま本文を改稿した.

- 解法の節を「導入の問い → 一般形 → 帰着先 → 一般の文字による主解法 → POINT → 例題 → 発想・別解」の順に組み直した.特殊値だけで済ませていた導出(部分分数の係数,積和の公式,$x^n\log x$,$\e^{ax}\sin bx$ など)を一般の文字で書き下した.
- 手順を1〜2行で示す POINT 枠(`bookpoint`)を60か所に置いた.練習としての例題には【方針】【解答】【解法】を付けた.証明問題では【解答】を置かない.
- 思いつきにくい置換(区間の反転,逆数による置換など)は結論を先に示すと明言し,発想を例題の後に回した.

- 定義域や0除算などの条件は節の前提として一度まとめて断り,退化した場合は脚注へ移した.例題の解法では除外点と区間を書く.
- 語彙と表記をそろえた.算用数字(2つ,第1項),「0」「したがって」,不等号 `\le`・`\ge`,「第2次導関数」,片側極限 $h\to0+$.`scripts/verify-math-style.py` で数式表記と語彙を検査できるようにした.
