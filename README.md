# 積分の体系的解説

高校数学を出発点に、積分の意味、計算方法、定積分の応用、近似と広義積分までをつないで説明する日本語の教科書です。

- 第1版原稿（2026年10月）
- 全12章、例題75題、演習102題と全解答、図19点
- A4・161ページの完成PDFはGit履歴には含めず、正式版Releaseで配布する方針です。

## 原稿の構成

`main.tex`から前付、12章、解答、公式参照表、用語索引、参考資料を読み込みます。
漸化式の教科書の`発展-new`と同じく、章ごとにフォルダを置き、その中を番号付きの節フォルダに分けています。章・節の親ファイルが、子ファイルを`\input`で読み込みます。

| 単位 | ファイルの例 |
| --- | --- |
| 章 | `第11章 近似と広義積分/近似と広義積分.tex` |
| 節 | `第11章 近似と広義積分/02_台形公式とシンプソン公式/台形公式とシンプソン公式.tex` |
| 小節 | `第11章 近似と広義積分/02_台形公式とシンプソン公式/03_シンプソン公式の誤差を導く.tex` |

小節がある節では、小節ごとに番号付きの`.tex`ファイルを置きます。小節のない節では、節の親ファイルに本文をまとめます。章末問題も各章内の独立した節フォルダに置いています。

解答は`付録A 章末問題・総合演習の解答/`の中で章ごとに分け、公式参照表は`付録B 公式と解法の参照表/`の中で節ごとに分けています。はじめには`前付/`、用語索引と参考資料は`後付/`にあります。

すべての`\input`のパスは、`main.tex`のあるリポジトリのルートを起点とします。フォルダ名の番号は読み込み順を表し、番号なしの見出し（章末問題など）にも付けています。

## コンパイル

LuaLaTeXと日本語対応のTeX Live環境を使います。`texlive-lang-japanese`、`texlive-luatex`相当のパッケージと原ノ味フォントが必要です。

```sh
latexmk -lualatex -interaction=nonstopmode -halt-on-error main.tex
```

OverleafではLuaLaTeXを選び、`main.tex`をメイン文書にしてください。
